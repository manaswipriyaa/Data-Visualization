# Data Visualization

A collection of data visualisation projects and practice notebooks demonstrating the use of Python visualisation libraries to explore, analyse, and communicate data insights effectively.

---

## About

This repository contains visualisation work across multiple datasets - covering a range of chart types, storytelling techniques, and Python libraries. The focus is on building clear, meaningful, and aesthetically clean visualisations that communicate data insights at a glance.

---

## Projects & Notebooks

### 1. Exploratory Visualisations
- Distribution plots (histograms, KDE curves, box plots)
- Correlation heatmaps and pair plots
- Outlier detection using visual methods

### 2. Comparative Analysis Charts
- Bar charts and grouped bar charts for category comparisons
- Line charts for trend analysis over time
- Stacked charts for part-to-whole relationships

### 3. Relationship & Pattern Visualisations
- Scatter plots with regression lines
- Bubble charts encoding a third variable
- Heatmaps for matrix data

### 4. Dashboard-Style Layouts
- Multi-plot figure layouts using Matplotlib subplots
- Annotated charts with key insight callouts
- Colour-coded visualisations for segmentation

---

## Skills Demonstrated

- Choosing the right chart type for the data and message
- Building clean, readable visualisations with proper labels, titles, and colour schemes
- Combining multiple charts into a single analytical story
- Working with real-world datasets across domains (health, finance, sales, music)

cd Data-Visualization

# Install dependencies
pip install pandas numpy matplotlib seaborn jupyter

# Launch notebooks
jupyter notebook notebooks/
